# 📌 Overview

HRise is a modern Human Resource Management System (HRMS) that combines traditional workforce management with Artificial Intelligence to simplify hiring, employee management, and organizational operations.

The platform provides dedicated portals for:

* Management Admin
* Recruiter
* Senior Manager
* Employee
* Candidate

Each role has access to role-specific workflows while maintaining secure role-based access control.

# 🤖 AI Features

## 1. AI Resume Screening

Google Gemini AI analyzes candidate resumes and extracts:

* Skills
* Experience
* Qualifications
* Key strengths

Helping recruiters reduce manual screening effort.

---

## 2. AI Candidate Matching

The platform compares candidate profiles with job requirements and generates compatibility insights to support hiring decisions.

---

## 3. AI Performance Review Assistance

Managers receive AI-assisted insights during performance reviews, helping summarize:

* Strengths
* Weaknesses
* Growth Areas
* Performance Trends

---

## 4. AI Hiring Prediction Engine

A dedicated Python + Flask machine learning service predicts candidate suitability using historical hiring and evaluation data.

Built using:

* Python
* Flask
* Scikit-Learn

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/HRise-HRMS.git
cd HRise-HRMS
```

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

## ML Service Setup

```bash
cd ml-service
pip install -r requirements.txt
python api/app.py
```
